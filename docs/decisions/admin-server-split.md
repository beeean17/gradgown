# 학생용과 관리자용 서버를 나눈다

- 상태: 확정 (2026-11-14). 계정을 고르는 방식, 공용 코드, 관리자 쓰기의 범위는 2026-11-18에 확정했다. 포트는 제안이다
- 관련: [db-privileges.md](./db-privileges.md), [tech-stack.md](./tech-stack.md), [scope.md](./scope.md), [API 계약](../contracts/web-api.md)

## 결정

서버를 **학생용과 관리자용 둘로** 나눈다. 두 서버는 같은 MySQL 데이터베이스를 쓰지만 **서로 다른 DB 계정**으로 접속한다.

| 서버 | 상대하는 웹 | 접속하는 DB 계정 |
|---|---|---|
| 학생용 | 학생 웹 | 학생 계정 |
| 관리자용 | 관리자 앱 | 관리자 계정(조회), 마스터 계정(쓰기) |

## 이유

- **원본도 나뉘어 있다.** grad42는 학생 웹과 관리자 앱이 따로 배포되고, 서버 쪽도 학생 명령(`reservationCommand`, `mentoringCommand`)과 관리자 명령(`adminCommand`)이 다른 함수다. 관리자용 계약을 따로 정해야 한다는 점은 [API 계약](../contracts/web-api.md)을 정리하면서 드러났다.
- **DB 권한을 쓰려면 접속 계정이 달라야 한다.** MySQL 권한은 DB 계정 단위다. 한 서버가 한 계정으로 접속하면 학생 요청과 관리자 요청을 DB가 구분할 수 없다([db-privileges.md](./db-privileges.md)).
- **학생용 서버의 피해 범위가 줄어든다.** 학생용 서버에 버그가 있어도 예약을 지우거나 설정을 바꿀 수 없다는 것을 DB가 보장한다.

## 영향

- 서버 프로젝트가 둘이 된다. 테이블 정의와 도메인 규칙처럼 겹치는 부분을 어떻게 나눠 가질지 정해야 한다.
- 로컬에서 띄울 프로세스가 는다: MySQL, 학생용 서버, 관리자용 서버, 학생 웹, 관리자 앱.
- 테스트 로그인도 서버마다 따로다. 학생용 서버는 학생 계정으로, 관리자용 서버는 관리자·마스터 계정으로만 로그인한다([test-login.md](./test-login.md)).

## 관리자용 서버가 DB 계정을 고르는 방식 (확정, 2026-11-18)

관리자용 서버는 연결 풀을 둘 가진다. 조회 계정(`gradgown_admin`)의 풀과 마스터 계정(`gradgown_master`)의 풀이다. **요청마다 로그인한 사람의 등급으로 풀을 고른다.**

| 로그인한 사람 | 쓰는 DB 계정 | 조회 | 쓰기 |
|---|---|---|---|
| 관리자 | `gradgown_admin` | 된다 | MySQL이 거부한다 |
| 마스터 | `gradgown_master` | 된다 | 된다 |

- 관리자가 쓰기를 요청하면 **서버 코드가 아니라 MySQL이** 오류 1142로 거부한다. 서버는 그 오류를 `permission-denied`로 바꿔 응답한다([API 계약](../contracts/web-api.md)).
- 쓰기 요청 앞에 "마스터인가"를 검사하는 서버 코드를 두지 않는다. 두면 DB가 거부하는 경로가 앱에서 한 번도 실행되지 않는다. 역할 간 경계는 DB가 지킨다는 결정([db-privileges.md](./db-privileges.md))을 앱에서 끝까지 보이려는 것이다.
- 화면은 관리자에게 쓰기 버튼을 보이지 않는다. 이것은 편의이고 경계가 아니다.

검토한 대안은 작업의 종류로 고르는 것이었다(조회는 누구든 조회 계정으로, 쓰기는 마스터 계정으로 보내고 서버가 등급을 검사). 마스터의 조회도 읽기 전용 계정을 쓰는 장점이 있지만, 관리자의 쓰기를 막는 주체가 서버 코드가 된다.

## 공용 코드 (확정, 2026-11-18)

공용 모듈 `core` 하나와 서버 모듈 둘로 둔다([tech-stack.md](./tech-stack.md)의 "모듈 구성"). `core`는 도메인 규칙과 응답 타입만 담고, SQL과 DB 계정 설정은 서버마다 따로 가진다.

## 관리자 쓰기의 범위 (확정, 2026-11-18)

관리자용 서버의 쓰기는 **접수 열기·닫기 하나**다([scope.md](./scope.md)). 마스터 계정이 앱에서 쓰이는 곳이 이것이다.

## 포트 (제안)

| 서버 | 포트 |
|---|---|
| 학생용 | 8080 |
| 관리자용 | 8081 |

둘 다 `127.0.0.1`에만 연다([local-only.md](./local-only.md)).
